
# 🌱 Smart Agriculture Dashboard

A beginner-friendly web project designed to present agricultural field monitoring information in a clean dashboard.

## Features

- Soil moisture monitoring display
- Temperature and humidity cards
- Crop status indicator
- Interactive soil moisture slider
- Dynamic irrigation recommendation
- Responsive green-and-white user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- GitHub Pages

## How It Works

The dashboard displays sample agricultural readings. Users can adjust the soil moisture slider to see different irrigation recommendations based on simple demo thresholds.

## Important Note

The readings are sample values for demonstration and learning purposes. This project is not connected to real sensors or live farm data.

## Future Improvements

- Integrate real soil moisture sensors
- Display live weather information
- Add crop-specific irrigation thresholds
- Store historical field readings
